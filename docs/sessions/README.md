# Sessions

The narrative of the last working session: what was done, what was tried and
failed, and what was left open. Read it before starting work.

A new session replaces the previous one. By then whatever mattered from it has
graduated - facts to `../hosts/` and the other YAML files, choices to
`../decisions/`, failures to `../traps.yaml` - and git keeps the rest.

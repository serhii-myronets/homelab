title: Replace Glances with Pulse

Pulse replaced Glances as the shared infrastructure monitor. Its server is a
version-pinned Compose service on core, available only at `pulse.home`; native
agents report core/Docker and the Proxmox host. Homepage now links to Pulse
instead of rendering twelve transient Glances charts.

Glances was disabled and removed from both hosts only after both Pulse agents
reported successfully. The old installer was removed from `tools/` and
decision 0011 was superseded by decision 0013.

The Pulse server was initialized with authentication. Its credentials live
outside Git under `/srv/ssd/docker/secrets/pulse`. A privilege-separated
`pulse@pve!monitor` token with only `PVEAuditor` rights lets Pulse inventory
the standalone Proxmox node, its guests, storage and physical disks; eight
resources were returned after registration. `pulse.home` resolved to core and
passed HTTPS validation from the Mac, and Homepage returned its Pulse card.

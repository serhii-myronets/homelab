---

Pulse replaced Glances as the shared infrastructure monitor. Its server is a
version-pinned Portainer stack on core, available only at `pulse.home`; native
agents report core/Docker and the Proxmox host. Homepage now links to Pulse
instead of rendering twelve transient Glances charts.

Glances was disabled and removed from both hosts only after both Pulse agents
reported successfully. The old installer was removed from `tools/` and
decision 0011 was superseded by decision 0013.

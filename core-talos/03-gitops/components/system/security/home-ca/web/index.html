Homelab Local Authority

Certificates for the local .home sites are issued here. Trust this root once and the local sites stop warning.

Download root.crt

macOS

curl -O http://ca.home/root.crt
sudo security add-trusted-cert -d -r trustRoot \
  -k /Library/Keychains/System.keychain root.crt

iPhone, iPad

Open this page in Safari and download the file; install the profile in Settings, then turn the root on under General → About → Certificate Trust Settings.

Android

Settings → Security → Encryption & credentials → Install a certificate → CA certificate. Some apps ignore user-installed roots.

Windows

certutil -addstore -f Root root.crt
